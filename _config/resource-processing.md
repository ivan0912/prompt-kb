## 处理标准流程

### Step 1: 选择资源的一个章节

**输入**: 资源名称 + 具体章节/主题
**输出**: 明确的单一学习目标

```
示例:
✅ 正确: "DAIR.AI 的 Introduction 章节"
❌ 错误: "DAIR.AI 全部内容"
❌ 错误: "DAIR.AI + OpenAI 指南一起学"
```

---

### Step 2: 提炼核心概念

**禁止**:
- ❌ 全文翻译
- ❌ 逐段摘要
- ❌ 复制粘贴

**必须**:
- ✅ 用自己的话总结（3-5 句话）
- ✅ 提取可操作的关键技巧
- ✅ 识别与我工作场景的相关性

---

### Step 3: 生成中文提示词模板

**模板要求**:
- 全部中文
- 可直接复制使用
- 包含角色定义
- 包含约束条件
- 包含输出格式

**模板格式**:

````markdown
# [模板名称]

[适用场景简述]

---
角色: [定义 AI 扮演的角色]
任务: [具体任务描述]

## 约束条件
1. [约束 1]
2. [约束 2]
3. [约束 3]

## 输出格式
[期望的输出格式]

## 示例
输入: [示例输入]
输出: [示例输出]
---
````

---

### Step 4: 编写知识库条目

**必须填写的 15 个字段**:
1. 标题
2. 来源（资源+章节）
3. 主题类型
4. 核心概念
5. 适用场景
6. 不适用场景
7. 可复制的中文提示词模板
8. OpenClaw 使用方式
9. 单 Agent 适配度
10. 多 Agent 适配度
11. 常见失败
12. 修正提示
13. 示例
14. 推荐存放路径
15. 版本记录

---

### Step 5: 标注 Agent 类型

| 单 Agent | 多 Agent | 说明 |
|----------|----------|------|
| ★★★★★ | ★★☆☆☆ | 简单独立任务 |
| ★★★☆☆ | ★★★★☆ | 需要多角度分析 |
| ★★★★☆ | ★★★★☆ | 两者都适合 |
| ★★☆☆☆ | ★★★★★ | 需要并行处理 |

---

### Step 6: 安全检查

**检查清单**:

| 检查项 | 是 | 否 | 说明 |
|--------|----|----|------|
| 是否涉及文件操作？ | | | |
| 是否涉及命令执行？ | | | |
| 是否涉及邮件/消息发送？ | | | |
| 是否涉及日历/日程？ | | | |
| 是否涉及外部 API？ | | | |
| 是否涉及付费操作？ | | | |

**如果任何一项为"是"**: 在条目中加入"安全注意事项"章节，明确标注需要人工确认的步骤。

---

### Step 7: 实际测试

**测试要求**:
- 在 OpenClaw 中用实际任务测试模板
- 记录效果（成功/失败）
- 分析原因
- 根据测试结果更新条目

## 各类资源的处理要点

### DAIR.AI Prompt Engineering Guide

**优先学习顺序**:
1. Introduction（建立概念框架）
2. Basic Prompting（打好基础）
3. Advanced Prompting（提升技巧）
4. Reliability（提升可靠性）
5. Applications（应用场景）

**处理要点**:
- 注重实操，不是理论
- 每个技巧都要生成模板
- 结合 OpenClaw 实践

### OpenAI 官方指南

**特点**:
- 实用导向
- 示例丰富
- 偏 ChatGPT 使用

**处理要点**:
- 重点关注 ChatGPT 特有技巧
- 生成适合 ChatGPT 的模板
- 注意上下文窗口限制

### Anthropic Prompt Engineering

**特点**:
- 理论偏多
- 注重可靠性和安全性
- Claude 特有技巧

**处理要点**:
- 重点关注 Claude 特有能力
- 生成适合 Claude 的模板
- 注意 Constitutional AI 相关内容

### DeepLearning.AI 课程

**处理要点**:
- 完成课程练习
- 提取可复用内容
- 生成证书/完成记录（可选）

### B站教程

**处理要点**:
- 记录视频关键时间点
- 提取操作步骤
- 验证视频中方法的实际效果

---

## 禁止事项

1. ❌ 不做筛选，一次性处理大量资源
2. ❌ 原文复制，不做转化
3. ❌ 不测试，声称可用
4. ❌ 跳过安全检查
5. ❌ 不区分单/多 Agent 场景

---

## 输出标准

每个资源处理完成后，必须产出：

1. **知识库条目文件**: 按标准模板填写
2. **学习笔记**（可选）: 过程性思考
3. **测试记录**（如有）: 实际使用效果
