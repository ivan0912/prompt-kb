## 视频提示词核心维度

### 在图像维度基础上，视频额外关注：

### 1. 动作 (Action/Motion)
- 角色动作（走、跑、跳、手势）
- 物体运动（飘动、旋转、爆炸）
- 环境动态（云飘、水流、树叶）
- 动作幅度（小/中/大）

### 2. 镜头运动 (Camera Movement)
| 镜头类型 | 描述 | 适用场景 |
|----------|------|----------|
| 推镜头 (Dolly In) | 逐渐接近主体 | 聚焦、强调 |
| 拉镜头 (Dolly Out) | 逐渐远离主体 | 展示全貌 |
| 摇镜头 (Pan) | 水平转动 | 扫描环境 |
| 倾斜 (Tilt) | 垂直转动 | 仰视/俯视 |
| 跟拍 (Tracking) | 跟随主体移动 | 叙事 |
| 环绕 (Orbit) | 围绕主体旋转 | 展示立体感 |
| 固定 (Static) | 镜头不动 | 稳定叙事 |
| 手持 (Handheld) | 不稳定感 | 纪实、紧张感 |

### 3. 时间顺序 (Temporal Sequence)
- 开场设定（3-5秒）
- 主体发展（持续时间）
- 高潮/转折
- 结尾收束
- 总时长控制

### 4. 节奏 (Rhythm/Pacing)
- 快节奏（动作片、紧张感）
- 慢节奏（文艺片、氛围）
- 变速（慢动作、快动作）
- 韵律感（重复、对比）

### 5. 转场 (Transitions)
| 转场类型 | 描述 | 适用场景 |
|----------|------|----------|
| 硬切 (Cut) | 直接切换 | 快节奏 |
| 叠化 (Dissolve) | 渐变过渡 | 梦境、回忆 |
| 淡入淡出 (Fade) | 亮度渐变 | 章节分隔 |
| 推拉转场 | 推/拉到黑 | 场景转换 |
| 特效转场 | 旋转、缩放等 | 创意短片 |

### 6. 画面稳定性 (Stability)
- 超稳定（商业广告）
- 轻微晃动（手持感）
- 明显晃动（运动相机）
- 创意不稳定（表达情绪）

### 7. 质量要求
- 分辨率（720p / 1080p / 4K）
- 帧率（24fps / 30fps / 60fps）
- 时长（3s / 5s / 10s /更长）
- 画面质量（高/中/低）

## 工具专项说明

### Sora
- **优势**: 时长长（最长20s），物理模拟好
- **劣势**: 等待时间长
- **技巧**: 详细描述场景和动作

### Runway
- **优势**: 风格多样，编辑功能强
- **劣势**: 单次生成时长有限
- **技巧**: 使用关键帧控制

### Pika
- **优势**: 文字驱动强，生成快
- **劣势**: 运动幅度有限
- **技巧**: 精确的动作描述

### Kling (可灵)
- **优势**: 国产中文友好，长镜头
- **劣势**: 国际风格支持有限
- **技巧**: 中文提示词效果更好

### Luma Dream Machine
- **优势**: 写实质量高
- **劣势**: 生成速度慢
- **技巧**: 详细的场景描述

### 豆包视频
- **优势**: 中文理解好，本土化
- **劣势**: 特效类较弱
- **技巧**: 简洁明确的描述

## 标准化流程

### 1. 需求分析
- 视频用途（广告/社交/电影）
- 时长要求
- 风格定位
- 目标受众

### 2. 分镜规划
- 设计关键画面
- 规划镜头运动
- 设计转场节奏

### 3. 提示词构建
- 每帧详细描述
- 镜头运动指令
- 节奏/时长控制
- 转场说明

### 4. 生成与迭代
- 分镜生成
- 片段拼接
- 迭代优化

### 5. 后期处理（如需要）
- 剪辑拼接
- 音频添加
- 调色统一

### 6. 结果归档
- 保存成功提示词
- 记录镜头序列
- 归入对应分类
