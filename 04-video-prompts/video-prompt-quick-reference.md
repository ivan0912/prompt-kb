## 1. 用途

- 只有一句口语化视频需求，想快速转成结构化视频提示词；
- 想检查已有视频提示词是否覆盖了关键维度；
- 想快速补充动作描述、镜头运动、时间顺序、负面限制；
- 想判断当前任务复杂度（L1-L5）以及是否需要拆分镜；

## 2. 视频提示词核心公式

```
视频提示词 = 主体 + 场景 + 动作 + 镜头运动 + 风格 + 构图 + 光线 + 色彩
           + 时间顺序 + 节奏 + 时长 + 首帧/末帧 + 负面限制 + 平台适配
```

不是每次都要写满所有项。简单任务可以简化，复杂任务才需要完整结构。

> ⚠️ **关键提醒**：如果没有「动作」和「镜头运动」两个维度，视频提示词很容易退化成**"动图版图片提示词"**——生成的视频可能只有无意义的抖动或形变，而不是有设计的动态效果。

## 3. 20 维度速查表

| # | 维度 | 什么时候必填 | 怎么写 | 常见错误 |
|---|------|-------------|--------|----------|
| 1 | **视频目标** | ⭐⭐⭐ 必须 | 一句话说明用途："产品展示短视频"、"概念宣传片" | ❌ 跳过不写，后续维度失去导向 |
| 2 | **主体** | ⭐⭐⭐ 必须 | 外观 + 位置 + 初始状态："银色金属水壶，置于大理石台面中央" | ❌ 只写名称不写外观（如只写"一个杯子"） |
| 3 | **场景** | ⭐⭐⭐ 必须 | 环境元素 + 空间关系："极简白色工作室，背景有落地窗" | ❌ 场景过于简陋，主体缺乏环境依托 |
| 4 | **动作** | ⭐⭐⭐ 几乎必须* | 谁 + 做什么 + 方向 + 速度 + 幅度 + 起止 + 循环（详见 §7） | ❌ 不写动作，视频没有有意义的变化 |
| 5 | **镜头运动** | ⭐⭐ L2+ 推荐 | 运镜方式 + 速度 + 路径（详见 §8） | ❌ 只写"电影感"而不说具体运镜方式 |
| 6 | **时间顺序** | ⭐⭐ L2+ 推荐 | 开始 → 变化 → 结束（详见 §9） | ❌ 没有时间线，缺乏叙事逻辑 |
| 7 | **节奏** | ⭐ L3+ 推荐 | 快/慢/渐进/突变/循环 | ❌ 节奏与内容不符（安静场景配快节奏） |
| 8 | **风格** | ⭐⭐⭐ 必须 | 风格关键词 + 一致性要求："电影级写实风格，全程保持" | ❌ 风格关键词堆砌且互相矛盾 |
| 9 | **构图** | ⭐⭐ 推荐 | 构图法则 + 主体位置："三分法构图，主体偏左三分之一处" | ❌ 不写构图，主体位置不可控 |
| 10 | **镜头 / 景别** | ⭐⭐ 推荐 | 远景/全景/中景/近景/特写（可配合景别变化） | ❌ 景别与内容不匹配（如产品展示用远景） |
| 11 | **光线** | ⭐⭐ 推荐 | 光源类型 + 方向 + 强度 + 色温 + 时间变化 | ❌ 光线静态化，不考虑视频中光线自然变化 |
| 12 | **色彩** | ⭐⭐ 推荐 | 主色 + 辅助色 + 色彩情绪 + 统一性要求 | ❌ 色彩太抽象（如"好看的颜色"） |
| 13 | **材质与细节** | ⭐⭐ 有主体时必填 | 材质关键词 + 细节要点："哑光金属表面，有细微拉丝纹理" | ❌ 忽略材质，渲染质感差 |
| 14 | **氛围** | ⭐ 可选 | 氛围形容词 + 情绪曲线："从神秘逐渐转为温暖" | ❌ 氛围与动作/光线不一致 |
| 15 | **时长** | ⭐⭐⭐ 必须 | 秒数：3s / 5s / 8s / 10s / 15s / 30s | ❌ 时长与内容量不匹配 |
| 16 | **画面比例** | ⭐⭐ 推荐 | 16:9 / 9:16 / 1:1 / 其他 | ❌ 不写比例，默认值可能与目标平台不符 |
| 17 | **首帧** | ⭐⭐ L2+ 推荐 | 主体位置 + 场景状态 + 光线 + 初始动作（详见 §10） | ❌ 不指定首帧，开头突兀 |
| 18 | **末帧** | ⭐⭐ L2+ 推荐 | 最终状态 + 镜头位置 + 是否循环（详见 §10） | ❌ 不指定末帧，结尾不自然 |
| 19 | **负面提示词** | ⭐⭐⭐ 必须 | 视频负面词列表（详见 §11） | ❌ 只复制图像负面词，遗漏视频特有问题 |
| 20 | **平台适配说明** | ⭐⭐ 有明确平台时必填 | 平台名 + 特殊注意事项（详见 §12） | ❌ 写死具体参数版本号 |

> \* 特殊例外：纯氛围/纯场景类视频（云海翻涌、水面波光），"动作"可以是环境本身的自然运动而非主体的主动行为。

## 5. 标准输出区

视频提示词生成器推荐输出结构：

| # | 输出项 | 内容说明 | 何时省略 |
|---|--------|---------|---------|
| 1 | **需求解析** | 将原始需求拆解为结构化要素 | 不省略 |
| 2 | **视频目标** | 明确视频用途、受众和预期效果 | 不省略 |
| 3 | **中文视频提示词** | 结构化的中文提示词正文 | 不省略 |
| 4 | **英文视频提示词** | 对应的英文提示词（大多数模型主要支持英文） | 仅当用户明确不需要时省略 |
| 5 | **动作与镜头运动说明** | 以文字解释动作设计和运镜意图 | L1 可简化 |
| 6 | **时间顺序 / 分镜结构** | 时间线描述或分镜表格 | L1 用简单时间线；L4-L5 用分镜表 |
| 7 | **负面提示词** | 需要排除的视频负面因素列表 | 不省略 |
| 8 | **平台适配建议** | 针对目标平台的调整建议 | 无明确平台时可省略 |
| 9 | **可选变体** | 2-3 个不同风格的替代版本 | 用户明确需要时提供 |
| 10 | **风险与注意事项** | 可能失败的地方、一致性风险、合规提醒 | L4-L5 或敏感任务必须包含 |
| 11 | **需要补充的问题** | 向用户确认的未明确信息清单 | 不省略 |

### 简化规则

| 复杂度等级 | 最小输出集 |
|-----------|-----------|
| **L1-L2**（简单任务） | 需求解析 + 中文视频提示词 + 英文视频提示词 + 负面提示词 + 需要补充的问题 |
| **L3**（多动作任务） | 上述 + 动作与镜头运动说明 + 时间顺序 |
| **L4-L5**（商业/复杂任务） | **全部 11 项** |

## 6. 复杂度速查

| 等级 | 任务特征 | 推荐做法 | 是否需要分镜 | 是否需要人工确认 |
|------|----------|----------|-------------|----------------|
| **L1** | 简单动态画面（云朵飘动、水面波光、光影扫过） | 单段提示词 + 时长 + 负面词 | ❌ 不需要 | ❌ 不需要 |
| **L2** | 单主体 + 简单动作（产品缓慢旋转、人物站立微表情） | 单段提示词 + 动作 + 镜头运动 + 首帧 | ❌ 不需要 | ❌ 一般不需要 |
| **L3** | 多动作 / 明确镜头运动（人物走过场景并交互、产品从包装中取出） | 单段/三段式 + 时间顺序 + 节奏 + 首末帧 | 可选（2-3 个镜头） | ✅ 建议确认关键帧 |
| **L4** | 产品展示 / 广告 / 多镜头结构（品牌宣传片片段、电商主图视频） | 三段式或分镜结构 + 转场 + 完整负面词 | ✅ 需要（3-6 个镜头） | ✅ 必须确认 |
| **L5** | 高价值商业视频 / 复杂叙事 / 多场景 / 强一致性要求（TVC 片段、品牌故事） | 完整分镜脚本 + 风险评估 + 多轮迭代 | ✅ 需要（6+ 镜头） | ✅ 必须全流程参与 |

### 快速判断策略

```
用户需求
  │
  ├─ 只有氛围/场景变化？ → L1
  │
  ├─ 一个东西在动？ → L2
  │
  ├─ 有多个动作或有明确运镜？ → L3
  │
  ├─ 是为了卖东西 / 品牌宣传？ → L4
  │
  └─ 高预算 / 多人审核 / 不能出错？ → L5
```

## 7. 动作描述速查

### 动作公式

```
动作 = 谁在动 + 做什么 + 方向 + 速度 + 幅度 + 起点/终点 + 是否循环 + 是否自然
```

### 常见动作词

| 类别 | 动作词示例 | 适用场景 |
|------|-----------|---------|
| **旋转类** | 缓慢旋转、顺时针/逆时针旋转、360°旋转 | 产品展示、物体全方位呈现 |
| **位移类** | 从左向右移动、轻轻漂浮、向上漂浮、缓慢滑入/滑出 | 主体入场/出场、场景过渡 |
| **显隐类** | 逐渐浮现、逐渐消失、淡入、淡出 | 氛围营造、转场衔接 |
| **镜头推拉** | 缓慢推近、平稳后拉、慢速变焦 | 聚焦强调、揭示环境 |
| **稳定运动** | 平稳移动、轻微摆动、匀速平移 | 优雅展示、专业质感 |
| **自然环境** | 水面波动、云层移动、烟雾飘散、光线扫过 | 自然场景、氛围视频 |
| **UI/数字** | UI 卡片展开、数据流动、粒子螺旋上升 | 科技感、概念视频、UI 演示 |

### 常见错误

| 错误写法 | 问题 | 正确写法 |
|---------|------|---------|
| "让它动起来" | 没有说谁动、怎么动、往哪动 | "产品自身在中心位置缓慢顺时针旋转 360 度" |
| "有各种动作" | 动作太多，每个都做不好 | 选 1-2 个核心动作，少即是多 |
| "向那边移动" | 方向不清 | "从画面左侧向右侧水平移动" |
| "快速地转动" | 速度和幅度不够精确 | "在 5 秒内完成一圈均匀旋转" |
| 没有起点和终点 | 不知道动作从哪里开始到哪里结束 | "从正面开始，转到背面，停在侧面 45 度角" |

## 8. 镜头运动速查

| 镜头运动 | 适合场景 | 一句话写法 |
|---------|---------|-----------|
| **固定镜头** (Static shot) | 采访、产品静物、需稳定展示 | "固定镜头，画面稳定不动" |
| **推镜** (Dolly in) | 强调主体、聚焦细节、制造紧张感 | "镜头缓慢向前推进，主体逐渐变大" |
| **拉镜** (Dolly out) | 揭示环境、开放结局、展示全貌 | "镜头缓慢向后拉远，逐步展现周围环境" |
| **横移** (Pan / Truck) | 展示宽幅场景、跟随水平运动主体 | "镜头从左向右平稳横移" |
| **环绕** (Orbit / Arc shot) | 产品全方位展示、突出立体感 | "镜头围绕主体做 180 度弧形运动，高度保持平视" |
| **跟拍** (Tracking shot) | 人物/动物运动、驾驶场景 | "镜头跟随主体同步向前移动，保持主体在画面中心" |
| **俯拍下降** (Crane down) | 开场建立镜头、揭示场景全貌 | "镜头从高处缓缓下降，同时向前推进至主体" |
| **手持感** (Handheld) | 纪实感、第一人称视角、Vlog 风格 | "手持拍摄感，轻微不规则晃动" |
| **平滑航拍** (Smooth aerial) | 风光大场景、建筑展示、地理概览 | "平滑航拍镜头，大范围稳定运动，模拟无人机视角" |
| **慢速变焦** (Slow zoom) | 制造心理压迫感、聚焦情感表达 | "镜头位置不变，焦距缓慢放大主体" |
| **摇摄** (Tilt) | 展示高大物体、从地面到天空 | "镜头垂直向下摇动" |
| **升降** (Boom up/down) | 从低角度到平视转换、揭示高低关系 | "镜头垂直向上平稳升起" |

### 稳定性声明

如果需要**稳定画面**，请在提示词中加入以下任一表述：

- "平滑镜头运动"
- "稳定镜头 / stable camera"
- "smooth camera movement, no jitter"
- "无抖动 / no camera shake"

> 💡 **原则**：一个短视频建议只用 **1 种主运镜**。不要在 5 秒内混合推拉横移环绕等 4 种以上运镜。

## 9. 时间顺序 / 分镜速查

### 结构一：单段式（适合 L1-L2）

最简单的视频只需描述一个连续过程：

```
开始状态 → 动作/变化过程 → 结束状态
```

**示例**：开始：产品居中正面 → 变化：缓慢顺时针旋转 360° → 结束：回到初始位置

**适用**：3-8 秒简单动态画面、单动作展示

---

### 结构二：三段式（适合 L3-L4）

| 阶段 | 时间占比 | 目的 | 内容要点 |
|------|---------|------|---------|
| **开头** (Opening) | 0-15% | 吸引注意 / 建立场景 | 首帧画面 + 初始氛围 + 引导视线 |
| **中段** (Body) | 15-85% | 核心内容 / 主要动作 | 主要动作序列、信息传达、情感展开 |
| **结尾** (Closing) | 85-100% | 收束 / 行动召唤 / 循环准备 | 末帧画面、最终情绪、是否留过渡以便循环 |

**示例**（8 秒产品展示）：开头 0-1s（产品背面 45°，光线从左侧来）→ 中段 1-7s（旋转至正面再转到另一侧）→ 结尾 7-8s（停在最佳角度，淡出准备循环）

---

### 结构三：分镜结构（适合 L4-L5）

| 镜头编号 | 时长 | 画面 | 动作 | 镜头运动 | 转场 | 提示词 |
|---------|------|------|------|---------|------|--------|
| Shot 01 | 0-3s | `[画面]` | `[动作]` | `[运镜]` | `[切入]` | `[核心提示词]` |
| Shot 02 | 3-6s | `[画面]` | `[动作]` | `[运镜]` | `[切入]` | `[核心提示词]` |
| Shot 03 | 6-10s | `[画面]` | `[动作]` | `[运镜]` | `[切入]` | `[核心提示词]` |
| （按需增加行） | | | | | | |

### 分镜编写原则

| # | 原则 | 说明 |
|---|------|------|
| 1 | **数量克制** | 15 秒以内视频不超过 4-6 个镜头 |
| 2 | **一镜一目的** | 每个镜头必须有明确的叙事或展示目的 |
| 3 | **转场服务内容** | 淡入淡出用于情绪转换，硬切用于节奏加快 |
| 4 | **主体一致性** | 不同镜头中的同一主体需重复关键外观描述 |
| 5 | **光线连续性** | 镜头之间光线逻辑合理衔接 |
| 6 | **预留过渡** | 如需无缝循环，末镜应能自然过渡回首镜 |

### 复杂度与结构的对应关系

| 复杂度 | 推荐结构 |
|--------|---------|
| L1-L2 | 单段式 |
| L3 | 单段式 或 三段式 |
| L4-L5 | 三段式 或 分镜结构 |

> ⚠️ **不建议**：简单视频滥用分镜（L1-L2 任务不需要分镜，单段即可）。

## 10. 首帧 / 末帧速查

| 项目 | 需要说明什么 | 常见错误 |
|------|-------------|---------|
| **首帧** | 主体位置、场景状态、光线条件、构图、即将开始的动作状态 | ❌ 不指定首帧，视频开头突兀/黑屏跳变 |
| **末帧** | 主体最终状态、动作是否完成、镜头停留位置、情绪氛围、是否可循环 | ❌ 不指定末帧，结尾戛然而止或不自然 |
| **是否循环** | 末帧是否能自然过渡回首帧（用于无缝 loop 播放） | ❌ 说要循环但首末帧差异太大 |
| **主体状态** | 开始时 vs 结束时主体的姿态/位置/外观 | ❌ 主体在过程中发生意料之外的状态改变 |
| **镜头停留位置** | 结束时相机的位置和朝向 | ❌ 镜头停在不理想的角度 |

### 快速写作模板

```
首帧：[主体] 位于 [位置]，[场景状态]，[光线条件]，[即将开始的动作]

末帧：[主体] 最终处于 [状态]，[动作完成情况]，[镜头位置]，[是否适合循环]
```

## 11. 负面提示词速查

### 视频通用负面提示词（15 条）

| # | 负面限制 | 英文（供参考） |
|---|---------|---------------|
| 1 | 不要水印 | watermark, text overlay |
| 2 | 不要 logo | logo, brand mark |
| 3 | 不要乱码文字 | gibberish text, random letters |
| 4 | 不要闪烁 | flickering, strobe effect |
| 5 | 不要画面抖动 | camera shake, jittery footage（除非故意手持感） |
| 6 | 不要主体变形 | morphing, body distortion |
| 7 | 不要多余肢体 | extra limbs, extra fingers |
| 8 | 不要脸部崩坏 | deformed face, bad anatomy, facial distortion |
| 9 | 不要产品形态变化 | product changing shape, inconsistent form |
| 10 | 不要背景跳变 | background jumping, scene cutting（除非有意转场） |
| 11 | 不要过度运动模糊 | excessive motion blur |
| 12 | 不要突然切换风格 | sudden style change, style inconsistency |
| 13 | 不要不自然转场 | abrupt transition, unnatural cut |
| 14 | 不要低清 | low quality, low resolution, blurry |
| 15 | 不要侵权角色 | copyrighted characters |

### 分类额外负面词

**人物/角色视频** 额外添加：

```
bad anatomy, mutated hands, extra fingers, poorly drawn faces,
disfigured, out of frame, extra limbs, ugly, duplicate,
morbid, mutilated, poorly drawn hands, poorly drawn face,
mutation, deformed, bad proportions, cloned face,
gross proportions, malformed limbs, missing arms/legs,
extra arms/legs, fused fingers, too many fingers, long neck
```

**产品视频** 额外添加：

```
product deformation, inconsistent shape, changing dimensions,
distorted geometry, warped surface, material inconsistency,
logo appearing, text on product, incorrect reflections
```

**场景/氛围视频** 额外添加：

```
inconsistent lighting, color banding, compression artifacts,
aliasing, noise, grain (unless intentional film grain)
```

> ⚠️ **重要**：不同平台对负面提示词支持不同。
>
> - **支持独立负面提示词字段** → 直接使用上述列表
> - **不支持独立字段** → 将关键负面限制写入自然语言提示词，格式如："The video should NOT contain: watermark, logo, text, flickering..."
> - **有字符限制** → 优先保留最关键的 5-8 条：水印 / logo / 变形 / 闪烁 / 文字 / 低质 / 抖动 / 脸部崩坏

## 12. 平台适配速查

| 平台类型 | 适合写法 | 注意事项 |
|---------|---------|---------|
| **Runway** | 英文提示词为主 | 运动笔刷控制强，支持首帧/末帧图输入；运动强度可通过笔刷精细调节 |
| **Pika** | 英文提示词 | 效果丰富（爆炸/融化/挤压等），上手简单；注意控制效果不要过度 |
| **Kling / 可灵** | 中英文均可 | 中文理解好，时长可达 10s+，支持高分辨率；国内生态友好 |
| **Luma** | 英文提示词 | 运动真实感强，物理模拟较好；适合自然运动场景 |
| **Sora** | 英文提示词 | 物理世界模拟强，时长较长；注意内容合规要求 |
| **豆包 / 即梦** | 中文优先 | 中文原生支持好，融入字节产品体系；适合中文场景快速出片 |
| **其他** (Vidu/Hailuo/Minimax 等) | 视平台而定 | 各有特色，建议先测试小样确认效果倾向 |

### 通用适配原则

| # | 原则 |
|---|------|
| 1 | **英文兼容性最广** —— 即使是中文友好平台，英文通常也有更好效果 |
| 2 | **不要写死参数值** —— 如 "motion score: 5/10" 这类内部参数可能随版本变更 |
| 3 | **时长不超过平台上限** —— 提交前确认平台最大时长限制 |
| 4 | **确认比例支持** —— 不是所有平台都支持所有画面比例 |
| 5 | **首帧/末帧因平台而异** —— 不支持的用文字描述替代 |

> 📌 平台专项模板和实时参数将在后续文件中单独创建，本速查卡仅提供通用指导。

## 15. 可复制：视频提示词验收清单

在提交视频提示词之前，逐项检查：

### 基础完整性（6 项）

- [ ] **主体是否清楚**：读者能否仅凭提示词想象出主体长什么样？
- [ ] **场景是否清楚**：环境描述是否足以建立画面空间？
- [ ] **动作是否明确**：有没有说明谁、做什么动作、什么方向、多快？
- [ ] **镜头运动是否明确**：相机怎么动？速度如何？
- [ ] **时间顺序是否明确**：从开始到结束发生了什么？
- [ ] **节奏是否明确**：快还是慢？是否有变速？

### 视觉质量（6 项）

- [ ] **风格是否统一**：全文风格关键词是否一致？有无矛盾？
- [ ] **光线是否连续**：光线描述是否合理？会不会闪烁？
- [ ] **色彩是否统一**：是否有色彩偏移或色闪的风险？
- [ ] **材质是否稳定**：运动中的材质是否会出现闪烁或变形？
- [ ] **首帧是否明确**：视频开头画面是否可预测？
- [ ] **末帧是否明确**：视频结束状态是否可控？

### 负面限制（4 项）

- [ ] **是否有负面提示词**：是否列出了需要排除的因素？
- [ ] **是否避免闪烁**：负面词中是否包含 flickering / 闪烁相关？
- [ ] **是否避免主体变形**：负面词中是否包含 morphing / deformation 相关？
- [ ] **是否避免文字乱码**：负面词中是否包含 text / watermark / logo 相关？

### 技术适配（3 项）

- [ ] **是否说明画面比例**：16:9 / 9:16 / 1:1？
- [ ] **是否适配目标平台**：时长、比例、写法是否符合目标平台？
- [ ] **是否避免水印/logo**：负面词中是否包含？

### 迭代准备（1 项）

- [ ] **是否有下一步修改方向**：如果第一次生成不理想，知道该调哪些维度？

**通过标准**：L1-L2 至少完成基础完整性 6 项 + 负面限制 4 项；L3-L5 建议全部 **20 项**均 checked。

## 16. 常见错误速查

| # | 错误 | 表现 | 快速修正 |
|---|------|------|---------|
| 1 | **只写画面，不写动作** | 提示词全是静态画面描述，没有任何动词 | 加入动作七要素：谁/什么/方向/速度/幅度/起止/循环 |
| 2 | **只写风格，不写镜头运动** | 写了"电影感""大片风"但没说相机怎么动 | 替换为具体运镜：推/拉/环绕/横移 + 速度 |
| 3 | **没有时间顺序** | 读者不知道视频从头到尾发生了什么 | 加入时间结构：开始→变化→结束 |
| 4 | **动作太多** | 一个 5 秒视频写了 8 个动作，每个都做不好 | 砍到 1-2 个核心动作，少即是多 |
| 5 | **镜头运动太复杂** | 又推又拉又环绕又手持，5 秒内换 4 种运镜 | 选一种主运镜贯穿全视频 |
| 6 | **分镜过多** | 8 秒视频切了 10 个镜头，每个不到 1 秒 | 精简到 3-4 个镜头，给每个足够时长 |
| 7 | **主体不一致** | Shot 01 是"银色产品"，Shot 02 变成了"金色产品" | 每个镜头重复完整的外观描述 |
| 8 | **风格跳变** | 前半段写实风，后半段突然变动漫风 | 全文锁定一个主风格 |
| 9 | **光线闪烁** | 视频播放时亮度忽明忽暗 | 负面词加 "flickering"；提示词加 "stable consistent lighting" |
| 10 | **产品形态变化** | 产品在旋转过程中形状变了 | 负面词加 "product deformation" / "inconsistent form" |
| 11 | **人物脸部崩坏** | 人物视频中面部五官错位或变形 | 负面词加详细的面部负面词（见 §11 分类额外词） |
| 12 | **文字乱码** | 画面中出现无法辨认的文字 | 负面词加 "text, watermark, letters, words, writing" |
| 13 | **平台参数写死** | 提示词里写了 "motion=5, CFG=7" 等具体参数值 | 改为描述性的运动要求，不以具体参数值呈现 |
| 14 | **没有负面提示词** | 完全没有说明"不要什么" | 至少加入基础 8 条负面限制 |
| 15 | **没有说明首帧/末帧** | 不知道视频开头和结尾什么样 | 补充首帧和末帧描述（见 §10） |

## 17. 推荐使用流程

```
1. 先写原始需求（一句话也行）
   ↓
2. 判断复杂度 L1-L5（见 §6）
   ↓
3. 明确主体和场景（必填，第 2-3 维度）
   ↓
4. 补充动作描述（第 4 维度，核心差异！）
   ↓
5. 补充镜头运动（第 5 维度，核心差异！）
   ↓
6. 补充时间顺序 / 选择结构（§9：单段/三段/分镜）
   ↓
7. 补充风格、构图、光线、色彩等视觉维度
   ↓
8. 补充负面提示词（第 19 维度，必填！）
   ↓
9. 补充首帧/末帧（第 17-18 维度，L2 以上推荐）
   ↓
10. 用验收清单逐项检查（§15）
    ↓
11. 根据生成结果二次优化
```
