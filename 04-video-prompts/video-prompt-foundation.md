## 1. 规范目标

本规范解决以下问题：

| # | 问题 | 说明 |
|---|------|------|
| 1 | **口语化视频需求无法直接生成高质量视频** | 用户说"做个酷炫的产品展示视频"，AI 不知道什么动作、什么镜头运动、什么节奏 |
| 2 | **视频提示词结构不统一** | 有人只写画面描述，有人只写风格词，缺少完整的时间和运动维度 |
| 3 | **视频和图像提示词混淆** | 把图像提示词照搬到视频生成，缺少动作、镜头运动、时间顺序等核心差异 |
| 4 | **动作、镜头运动、时间顺序缺失** | 最常见的失败：生成的视频只是"会动的图片"，没有有意义的动态设计 |
| 5 | **首帧/末帧控制缺失** | 不指定开头和结束状态，视频开头突兀或结尾不自然 |
| 6 | **负面提示词不适用视频** | 直接套用图像负面限制（如"不要低质量"），忽略视频特有的闪烁、变形、抖动等问题 |
| 7 | **分镜结构使用不当** | 简单任务过度拆分分镜，复杂任务不分镜导致失控 |

**核心定位**：视频提示词的核心是**连续画面的变化设计**，不是单帧视觉描述。本规范在 T-IMG-001 的 15 个视觉维度基础上，新增动作、镜头运动、时间顺序、节奏、转场、首帧/末帧、时长、画面稳定性等视频专属维度。

### 本规范不解决

| # | 不解决的问题 | 原因 |
|---|-------------|------|
| 1 | 具体平台的实时参数 | 平台参数频繁变动，以各平台官方文档为准 |
| 2 | 视频生成结果完全可控 | 当前 AI 视频生成技术仍有随机性，本规范只能提高成功率 |
| 3 | 真实人物身份还原 | 涉及隐私和伦理风险，本规范不覆盖 |
| 4 | 高风险 / 侵权 / 敏感视频生成 | 涉及商标、版权、敏感内容，本规范不覆盖 |
| 5 | 替代具体平台官方文档 | 本规范是通用方法论，不替代任何平台的官方指南 |

## 2. 与图像提示词模块的关系

T-VIDEO-001 继承自 T-IMG-001（图像提示词基础规范），并在其基础上扩展时间维度：

```
T-IMG-001  图像提示词基础规范（单帧画面）
    │  → 定义 15 个视觉维度（主体/场景/风格/构图/镜头/光线/色彩/材质/氛围/比例/质量/负面/参考图/平台/目标）
    │
    └─→ T-VIDEO-001  视频提示词基础规范（连续画面）[本文档]
         → 继承全部视觉维度
         → 新增 8 个视频专属维度（动作/镜头运动/时间顺序/节奏/转场/首帧/末帧/画面稳定性）
```

### 维度对比

| 维度 | 图像提示词 (T-IMG-001) | 视频提示词 (T-VIDEO-001) |
|------|------------------------|--------------------------|
| **主体** | 静态外观描述 | 外观 + 动作中的状态变化 |
| **场景** | 静态环境描述 | 环境 + 可能的场景变化（日夜交替、天气变化等） |
| **风格** | 单一风格关键词 | 风格 + 时间内的风格一致性要求 |
| **构图** | 单一构图方式 | 构图 + 镜头运动中的构图变化 |
| **镜头 / 景别** | 固定景别 | 景别 + 运动过程中的景别切换 |
| **光线** | 固定光线描述 | 光线 + 光线随时间的自然变化 |
| **色彩** | 调色板 / 色彩关键词 | 色彩 + 整段视频的色彩统一性 |
| **材质细节** | 材质关键词 | 材质 + 避免材质闪烁/跳变的约束 |
| **氛围** | 氛围形容词 | 情绪曲线 / 氛围渐变 |
| **负面提示词** | 静态负面词 | 负面词 + 视频特有的动态负面约束 |
| **平台适配说明** | 图像平台参数建议 | 视频平台参数建议（时长/帧率/运动强度等） |
| **图像目标** | 封面图/产品图/插画等 | —— |
| **动作** | —— | ✅ 新增：谁/什么/方向/速度/幅度/循环 |
| **镜头运动** | —— | ✅ 新增：推拉移绕跟拍等运镜方式 |
| **时间顺序** | —— | ✅ 新增：开始→变化→结束的时间线 |
| **节奏** | —— | ✅ 新增：快慢/渐进/突变/循环 |
| **首帧 / 末帧** | —— | ✅ 新增：开头和结束的画面状态控制 |
| **画面稳定性** | —— | ✅ 新增：稳定/手持感/动感的选择 |

**一句话总结**：图像提示词关注"这一帧长什么样"，视频提示词关注"这些帧如何连贯地变化"。

## 3. 视频提示词核心公式

```
视频提示词 = 主体 + 场景 + 动作 + 镜头运动 + 风格 + 构图 + 光线 + 色彩
           + 时间顺序 + 节奏 + 时长 + 首帧/末帧 + 负面限制 + 平台适配
```

### 使用原则

| 场景 | 推荐做法 | 说明 |
|------|---------|------|
| **简单动态画面 (L1)** | 主体 + 动作 + 时长 + 负面限制 | 如"云层缓慢飘过山峰" |
| **单主体展示 (L2)** | + 镜头运动 + 风格 + 首帧 | 如"产品 360° 旋转展示" |
| **多动作视频 (L3)** | + 时间顺序 + 节奏 + 末帧 | 如"人物走进咖啡馆并坐下" |
| **产品/广告视频 (L4)** | + 分镜结构 + 转场 + 光线变化 | 完整商业视频 |
| **高价值商业视频 (L5)** | 全部维度 + 人工确认关键帧 | 多轮迭代 |

### ⚠️ 关键警告

如果没有**动作**和**镜头运动**两个维度，视频提示词将退化成**"动图版图片提示词"**——生成的视频可能只有无意义的抖动或形变，而不是有设计的动态效果。

## 4. 视频提示词核心维度

### 4.1 核心维度总表

| # | 维度 | 作用 | 什么时候必填 | 怎么写 | 常见错误 |
|---|------|------|-------------|--------|---------|
| 1 | **视频目标** | 明确视频用途和预期效果 | 始终必填 | 一句话说明用途（如"产品展示短视频"、"概念宣传片"） | 跳过不写，导致后续所有维度失去导向 |
| 2 | **主体** | 视频中的核心对象 | 始终必填 | 外观 + 位置 + 初始状态（如"银色金属水壶，置于大理石台面中央"） | 只写名称不写外观（如只写"一个杯子"） |
| 3 | **场景** | 主体所处的环境 | 始终必填 | 环境元素 + 空间关系（如"极简白色工作室，背景有落地窗"） | 场景过于简陋，主体缺乏环境依托 |
| 4 | **动作** | 主体在视频中的行为或变化 | 几乎始终必填* | 谁 + 什么动作 + 方向 + 速度 + 幅度（详见 §9） | 不写动作，导致视频没有有意义的变化 |
| 5 | **镜头运动** | 相机如何移动 | L2 以上推荐必填 | 运镜方式 + 速度 + 路径（详见 §10） | 只写"电影感"而不说明具体运镜 |
| 6 | **时间顺序** | 内容按时间的组织方式 | L2 以上推荐必填 | 开始 → 变化 → 结束（详见 §11） | 没有时间线，视频缺乏叙事逻辑 |
| 7 | **节奏** | 动作速度和情绪张力 | L3 以上推荐必填 | 快/慢/渐进/突变/循环（详见 §12） | 节奏与内容不符（如安静场景配快节奏） |
| 8 | **风格** | 视觉风格和美学倾向 | 始终必填 | 风格关键词 + 一致性要求（如"电影级写实风格，全程保持"） | 风格关键词堆砌且互相矛盾 |
| 9 | **构图** | 画面元素的空间布局 | 推荐填写 | 构图法则 + 主体位置（如"三分法构图，主体偏左三分之一处"） | 不写构图，主体位置不可控 |
| 10 | **镜头 / 景别** | 拍摄距离和视角 | 推荐填写 | 远景/全景/中景/近景/特写（可配合景别变化） | 景别与内容不匹配（如产品展示用远景） |
| 11 | **光线** | 光源和光影效果 | 推荐填写 | 光源类型 + 方向 + 强度 + 色温 + 时间变化 | 光线描述静态化，不考虑视频中光线是否自然变化 |
| 12 | **色彩** | 配色方案和调色倾向 | 推荐填写 | 主色 + 辅助色 + 色彩情绪 + 统一性要求 | 色彩描述太抽象（如"好看的颜色"） |
| 13 | **材质与细节** | 表面纹理和精细特征 | 有主体时必填 | 材质关键词 + 细节要点（如"哑光金属表面，有细微的拉丝纹理"） | 忽略材质，导致渲染质感差 |
| 14 | **氛围** | 情绪感受和环境气氛 | 推荐填写 | 氛围形容词 + 情绪曲线（如"从神秘逐渐转为温暖"） | 氛围与动作/光线不一致 |
| 15 | **时长** | 视频总长度 | 始终必填 | 秒数（如 3s / 5s / 10s / 15s） | 时长与内容量不匹配 |
| 16 | **画面比例** | 宽高比 | 推荐填写 | 16:9 / 9:16 / 1:1 / 其他 | 不写比例，默认比例可能与目标平台不符 |
| 17 | **首帧** | 视频开头的画面状态 | L2 以上推荐必填 | 主体位置 + 场景状态 + 光线 + 初始动作（详见 §13） | 不指定首帧，开头突兀 |
| 18 | **末帧** | 视频结尾的画面状态 | L2 以上推荐必填 | 最终状态 + 镜头位置 + 是否循环（详见 §13） | 不指定末帧，结尾不自然 |
| 19 | **负面提示词** | 需要排除的内容 | 始终必填 | 视频负面词列表（详见 §14） | 只复制图像负面词，遗漏视频特有问题 |
| 20 | **平台适配说明** | 目标平台的特殊处理 | 有明确目标平台时必填 | 平台名 + 特殊注意事项（详见 §16） | 写死具体参数版本号 |

> \* 特殊例外：纯氛围/纯场景类视频（如云海翻涌、水面波光），"动作"可以是环境本身的自然运动而非主体的主动行为。

## 6. 标准输出结构

视频提示词生成器应按以下结构输出：

| # | 输出项 | 内容说明 | 何时省略 |
|---|--------|---------|---------|
| 1 | **需求解析** | 将原始需求拆解为结构化要素（主体/动作/场景/风格/平台/限制） | 不省略 |
| 2 | **视频目标** | 明确视频用途、受众和预期效果 | 不省略 |
| 3 | **中文视频提示词** | 结构化的中文视频提示词正文 | 不省略 |
| 4 | **英文视频提示词** | 对应的英文提示词（大多数视频生成模型主要支持英文） | 仅当用户明确不需要时省略 |
| 5 | **动作与镜头运动说明** | 以文字解释动作设计和运镜意图 | L1 简单任务可简化 |
| 6 | **时间顺序 / 分镜结构** | 时间线描述或分镜表格 | L1 用简单时间线；L4-L5 用分镜表 |
| 7 | **负面提示词** | 需要排除的视频负面因素列表 | 不省略 |
| 8 | **平台适配建议** | 针对目标平台的参数和写法调整建议 | 无明确目标平台时可省略 |
| 9 | **可选变体** | 2-3 个不同风格的替代版本 | 用户明确需要时提供 |
| 10 | **风险与注意事项** | 可能失败的地方、一致性风险、合规提醒 | L4-L5 或敏感任务必须包含 |
| 11 | **需要补充的问题** | 向用户确认的未明确信息清单 | 不省略 |

### 简化规则

| 复杂度等级 | 最小输出集 |
|-----------|-----------|
| **L1-L2**（简单任务） | 需求解析 + 中文视频提示词 + 英文视频提示词 + 负面提示词 + 需要补充的问题 |
| **L3**（多动作任务） | 上述 + 动作与镜头运动说明 + 时间顺序 |
| **L4-L5**（商业/复杂任务） | **全部 11 项**

## 7. 视频任务复杂度分级

| 等级 | 任务特征 | 推荐做法 | 是否需要分镜 | 是否需要人工确认 |
|------|---------|---------|-------------|----------------|
| **L1** | 简单动态画面（如云朵飘动、水面波光、光影扫过） | 单段提示词 + 时长 + 负面词 | ❌ 不需要 | ❌ 不需要 |
| **L2** | 单主体 + 简单动作（如产品缓慢旋转、人物站立微表情） | 单段提示词 + 动作 + 镜头运动 + 首帧 | ❌ 不需要 | ❌ 一般不需要 |
| **L3** | 多动作 / 明确镜头运动（如人物走过场景并交互、产品从包装中取出） | 单段/三段式提示词 + 时间顺序 + 节奏 + 首末帧 | 可选（2-3 个镜头） | ✅ 建议确认关键帧 |
| **L4** | 产品展示 / 广告 / 多镜头结构（如品牌宣传片片段、电商主图视频） | 三段式或分镜结构 + 转场 + 完整负面词 | ✅ 需要（3-6 个镜头） | ✅ 必须确认 |
| **L5** | 高价值商业视频 / 复杂叙事 / 多场景 / 强一致性要求（如 TVC 片段、品牌故事视频） | 完整分镜脚本 + 风险评估 + 多轮迭代 | ✅ 需要（6+ 镜头） | ✅ 必须全流程参与 |

### 选择策略

```
用户需求
  │
  ├─ 只有氛围/场景变化？ → L1
  │
  ├─ 一个东西在动？ → L2
  │
  ├─ 有多个动作或有明确运镜？ → L3
  │
  ├─ 是为了卖东西 / 品牌宣传？ → L4
  │
  └─ 高预算 / 多人审核 / 不能出错？ → L5
```

## 8. 主体描述规范

### 8.1 常见主体类型

| 类型 | 描述重点 | 示例 |
|------|---------|------|
| **人物** | 外貌、服装、姿态、表情、年龄感 | "一位穿着米色风衣的女性，30 岁左右，短发，神情自信" |
| **产品** | 形状、颜色、材质、尺寸感、品牌特征（不含 logo） | "圆柱形智能音箱，织物网罩，香槟金顶盖，直径约 10cm" |
| **动物** | 种类、外貌特征、姿态、表情 | "一只金色寻回犬，毛发蓬松，耳朵下垂，侧坐姿态" |
| **建筑** | 风格、材质、体量感、标志性特征 | "现代玻璃幕墙摩天楼，流线型外观，高度约 200 米" |
| **场景** | 地貌、建筑群、天气、时间 | "雪山脚下的湖泊，清晨薄雾，远处有松树林" |
| **图标 / UI** | 形状、颜色、层级关系、动效类型 | "深色卡片组件，包含头像圆形图标和两行文字" |
| **品牌视觉元素** | 品牌（不含 logo）、配色、字体风格、辅助图形 | "[某品牌] 标志性的红色和圆润设计语言" |
| **抽象概念** | 拟物化隐喻、符号、动态形态 | "由发光粒子组成的数据流动形态，呈螺旋上升状" |
| **自然物体** | 种类、状态、纹理 | "一块被打磨过的鹅卵石，表面光滑湿润" |
| **交通工具** | 型号类别、角度、状态 | "银色轿车的侧面 45 度角，静止状态" |

### 8.2 主体描述六要素

| # | 要素 | 说明 | 示例 |
|---|------|------|------|
| 1 | **外观** | 颜色、形状、大小、材质 | "黑色哑光金属机身，长方形，约手机大小" |
| 2 | **状态** | 当前姿态、开关状态、完整程度 | "屏幕亮着，竖直放置" |
| 3 | **位置** | 在场景中的空间位置 | "位于画面中央，放在木质桌面上" |
| 4 | **动作** | 正在做或即将做的行为（§9 详细展开） | "缓慢顺时针旋转" |
| 5 | **与环境关系** | 和周围物体的互动/空间关系 | "前方有一杯咖啡，背景是虚化的城市天际线" |
| 6 | **一致性要求** | 是否需要在整个视频中保持外观不变 | "产品外形必须在全程保持一致，不允许变形" |

### 8.3 一致性注意事项

视频生成模型目前对**主体一致性**的支持有限。以下情况需要特别标注：

| 情况 | 建议 |
|------|------|
| 产品外形不能变 | 在提示词中强调"保持产品形态一致" / "no morphing" |
| 人物面部不能崩坏 | 在负面提示词中加入"deformed face / facial distortion" |
| 同一物体出现在多个镜头 | 每个镜头都重复完整的外观描述 |
| 品牌 IP 角色 | ⚠️ 当前 AI 视频生成不建议用于精确 IP 还原 |

## 9. 动作描述规范

### 为什么动作描述至关重要

图像提示词描述的是"定格瞬间"，而视频提示词描述的是**过程**。没有明确的动作指示，AI 会自行猜测如何让画面"动起来"，结果往往是：

- 无意义的抖动或缩放
- 主体非自然的形变（morphing）
- 与预期完全不同的运动方式

### 9.1 动作描述七要素

| # | 要素 | 问题 | 示例 |
|---|------|------|------|
| 1 | **谁在动** | 动作的执行者是谁？ | "产品本身" / "相机移动" / "环境元素（云/水/光）" |
| 2 | **动作是什么** | 具体的行为或变化？ | "旋转" / "平移" / "膨胀" / "变色" / "浮现" |
| 3 | **动作方向** | 向哪个方向？ | "顺时针" / "从左向右" / "由远及近" / "向上漂浮" |
| 4 | **动作速度** | 快还是慢？ | "缓慢地" / "匀速" / "先慢后快" / "急促地" |
| 5 | **动作幅度** | 变化范围多大？ | "轻微晃动" / "360 度旋转" / "从画面外进入画面中心" |
| 6 | **起点和终点** | 从哪里开始、到哪里结束？ | "从正面开始，转到背面" / "从不可见到完全显示" |
| 7 | **是否循环** | 结束后是否回到初始状态？适合无缝循环播放？ | "循环" / "不循环" / "适合无缝 loop" |

### 9.2 动作描述示例库

| 类别 | 动作描述 | 适用场景 |
|------|---------|---------|
| **产品旋转** | 产品在中心位置缓慢顺时针旋转 360 度，转速均匀 | 产品展示视频 |
| **人物行走** | 人物从画面左侧走入，向右前方匀速行走，步态自然，至画面右侧三分之二处停下 | 场景展示 / 生活片段 |
| **环境运动** | 水面有轻微涟漪，波纹从中心向外扩散，节奏舒缓 | 自然场景 / 氛围视频 |
| **UI 动效** | 卡片组件逐个从下方淡入，每个间隔 0.5秒，伴随轻微上移弹性动画 | UI 演示 / 功能介绍 |
| **天气变化** | 云层从右向左缓慢漂移，速度约每 5 秒穿过画面一次，云的边缘被阳光照亮 | 延时摄影风格 / 场景氛围 |
| **光线运动** | 一束暖色调光线从画面右上方缓缓扫过场景，照亮不同区域，如同日落时分的阳光 | 氛围感 / 高端质感 |
| **粒子效果** | 发光的微小粒子围绕主体缓慢螺旋上升，密度适中，带有轻微拖尾 | 科技感 / 概念视频 |
| **镜头推近** | 主体保持在画面中心，镜头缓慢向前推进，使主体在画面中逐渐变大（模拟 dolly in） | 聚焦 / 强调 / 电影开场 |
| **缩放弹跳** | 主体轻微脉冲式放大再缩小，幅度 3%，节奏轻快 | 社交媒体 / 注意力吸引 |
| **场景变换** | 场景从白天平滑过渡到黄昏，天空颜色从蓝色渐变为橙紫色，城市灯光逐一亮起 | 时间推移 / 日夜循环 |

## 10. 镜头运动规范

### 10.1 常用镜头运动一览

| 镜头运动 | 英文术语 | 效果 | 适用场景 | 常见错误 |
|----------|---------|------|---------|---------|
| **固定镜头** | Static shot / Fixed camera | 画面稳定不动，聚焦主体动作 | 采访、产品静物、需要稳定的展示 | 用于需要动态感的场合显得呆板 |
| **推镜** | Dolly in / Push in | 镜头向前推进，主体逐渐变大 | 强调主体、聚焦细节、制造紧张感 | 推进太快导致眩晕 |
| **拉镜** | Dolly out / Pull out | 镜头向后拉远，主体逐渐变小 | 揭示环境、开放结局、展示全貌 | 拉远后主体太小失去焦点 |
| **横移** | Pan / Truck shot | 镜头水平左右移动 | 展示宽幅场景、跟随水平运动主体 | 移动速度与主体速度不匹配 |
| **环绕** | Orbit / Arc shot | 镜头围绕主体做圆周运动 | 产品全方位展示、突出主体立体感 | 环绕速度不均匀导致画面跳跃 |
| **跟拍** | Tracking shot | 镜头跟随主体同步移动 | 人物/动物运动、驾驶场景 | 跟拍轨迹不平滑 |
| **俯拍下降** | Crane down / High angle descent | 镜头从高处向下移动 | 开场建立镜头、揭示场景全貌 | 下降过程中构图失衡 |
| **手持感** | Handheld / Handheld feel | 模拟手持拍摄的轻微不规则晃动 | 纪实感、第一人称视角、Vlog 风格 | 用于需要稳定画面的正式场合 |
| **平滑航拍** | Smooth drone shot / Aerial | 模拟无人机航拍的平稳大范围运动 | 风光大场景、建筑展示、地理概览 | 运动范围过大导致细节模糊 |
| **慢速变焦** | Slow zoom in/out | 镜头位置不变，仅通过焦距变化改变主体大小 | 制造心理压迫感、聚焦情感表达、文艺片风格 | 与推镜混淆（变焦不改变透视关系） |
| **摇摄** | Tilt | 镜头垂直上下转动 | 展示高大物体、从地面到天空 | 摇动范围超出合理视角 |
| **升降** | Boom up/down | 镜头垂直向上或向下移动 | 从低角度到平视的转换、揭示高低关系 | 与俯拍混淆（升降是垂直位移） |

### 10.2 镜头运动写作原则

| # | 原则 | 说明 |
|---|------|------|
| 1 | **具体 > 抽象** | 写"镜头缓慢向前推进"而不是"电影感镜头" |
| 2 | **一个视频一种主运镜** | 不要在一个短视频中混合 5 种以上镜头运动 |
| 3 | **运镜服务内容** | 先想清楚"为什么要运动"，再决定怎么运动 |
| 4 | **说明速度** | "缓慢" / "匀速" / "先慢后快"——不说速度等于没说 |
| 5 | **稳定性声明** | 如果需要稳定画面，明确写"平滑镜头运动" / "稳定镜头" / "smooth camera movement" |

### 10.3 ⚠️ 常见错误

| 错误写法 | 问题 | 正确写法 |
|---------|------|---------|
| "电影感的镜头" | 没有说明具体运动方式 | "镜头缓慢环绕主体做 180 度弧形运动，高度保持平视" |
| "镜头动一下" | 方向、速度、幅度全未知 | "镜头从左侧向右侧横移，速度均匀，5 秒内完成" |
| "航拍大景" | 没说运动路径和焦点 | "航拍从高空缓缓下降同时向前推进，最终停留在产品正上方" |
| "手持感"但实际需要稳定画面 | 运动风格与视频目标矛盾 | "平滑稳定镜头运动" 或 "smooth stable camera movement" |

## 11. 时间顺序 / 分镜规范

### 11.1 三种时间结构

#### 结构一：单段式（适合 L1-L2）

最简单的视频只需描述一个完整的过程：

```
开始状态 → 动作/变化过程 → 结束状态
```

**示例**：

> 开始：产品位于画面中央，正面朝向观众，光线柔和
> 变化：产品缓慢顺时针旋转 360 度
> 结束：产品回到初始位置，完成一周旋转

**适用**：3-8 秒简单动态画面、单动作展示

---

#### 结构二：三段式（适合 L3-L4）

将视频分为三个有明确目的的阶段：

| 阶段 | 时间占比 | 目的 | 内容要点 |
|------|---------|------|---------|
| **开头 (Opening)** | 0-15% | 吸引注意 / 建立场景 | 首帧画面 + 初始氛围 + 引导视线 |
| **中段 (Body)** | 15-85% | 核心内容 / 主要动作 | 主要动作序列、信息传达、情感展开 |
| **结尾 (Closing)** | 85-100% | 收束 / 行动召唤 / 循环准备 | 末帧画面、最终情绪、是否留过渡以便循环 |

**示例**（8 秒产品展示视频）：

| 阶段 | 时长 | 内容 |
|------|------|------|
| 开头 | 0-1s | 产品在大理石台上，背面 45 度角，光线从左侧来 |
| 中段 | 1-7s | 产品旋转至正面，然后继续转到另一侧，光线在表面产生流动的高光 |
| 结尾 | 7-8s | 产品停在最佳展示角度，光线达到最美状态，淡出准备循环 |

---

#### 结构三：分镜结构（适合 L4-L5）

当视频需要多个不同镜头时，使用分镜表格：

| 镜头编号 | 时长 | 画面 | 动作 | 镜头运动 | 转场 | 提示词摘要 |
|---------|------|------|------|---------|------|-----------|
| Shot 01 | 0-3s | [画面描述] | [动作] | [运镜] | [切入方式] | [核心提示词] |
| Shot 02 | 3-6s | [画面描述] | [动作] | [运镜] | [切入方式] | [核心提示词] |
| Shot 03 | 6-10s | [画面描述] | [动作] | [运镜] | [切入方式] | [核心提示词] |

**分镜编写原则**：

| # | 原则 | 说明 |
|---|------|------|
| 1 | **数量克制** | 15 秒以内的视频建议不超过 4-6 个镜头 |
| 2 | **一镜一目的** | 每个镜头必须有明确的叙事或展示目的 |
| 3 | **转场服务内容** | 淡入淡出用于情绪转换，硬切用于节奏加快，避免花哨转场 |
| 4 | **主体一致性** | 不同镜头中的同一主体需保持外观一致（重复描述关键特征） |
| 5 | **光线连续性** | 镜头之间的光线逻辑应合理衔接 |
| 6 | **预留过渡** | 如果需要无缝循环，最后一个镜头应能自然过渡到第一个镜头 |

## 12. 节奏与时长规范

### 12.1 节奏描述要素

| # | 要素 | 说明 | 示例关键词 |
|---|------|------|-----------|
| 1 | **总时长** | 视频总长度 | 3s / 5s / 8s / 10s / 15s / 30s |
| 2 | **动作速度** | 主体运动的速度感 | 缓慢 / 匀速 / 轻快 / 急促 |
| 3 | **镜头节奏** | 镜头切换或运动的频率和速度 | 缓慢推进 / 连续快切 / 长镜头停留 |
| 4 | **变速** | 是否有速度变化 | 先慢后快 / 渐入高潮 / 突然加速 |
| 5 | **循环性** | 是否适合无缝循环 | seamless loop / 可以循环 / 不循环 |
| 6 | **平台适配** | 是否符合目标平台的节奏偏好 | 抖音快节奏 / 小红书舒缓 / B 站中等节奏 |

### 12.2 常见时长建议

| 时长 | 适用场景 | 复杂度建议 | 注意事项 |
|------|---------|-----------|---------|
| **3 秒** | 简单动态效果、GIF 风格、社交媒体贴纸 | L1 | 内容必须极其精炼，一个动作就够 |
| **5 秒** | 单主体展示、产品旋转、氛围变化 | L1-L2 | 最多 1-2 个动作变化 |
| **8 秒** | 产品展示、场景变化、简单叙事 | L2-L3 | 可包含 2-3 个阶段的变化 |
| **10-15 秒** | 广告短片、多镜头结构、品牌展示 | L3-L4 | 建议使用三段式或简单分镜 |
| **30 秒以上** | 完整叙事、教学视频、TVC 片段 | L4-L5 | **强烈建议拆分为完整分镜结构** |

### 12.3 时长的平台考量

| 平台 / 场景 | 推荐时长 | 说明 |
|------------|---------|------|
| 抖音 / TikTok 信息流 | 5-8s（黄金前 3 秒） | 前 3 秒决定用户是否停留 |
| 小红书 | 5-15s | 偏好精致、有审美感的节奏 |
| 微信朋友圈 / 公众号 | 6-10s | 不宜过长，静音环境下也要能看懂 |
| 电商详情页主图视频 | 5-15s | 重点展示产品，不宜加入过多叙事 |
| 网站 Banner / Landing Page | 5-10s | 通常自动播放且循环，需考虑静音体验 |
| 演示文稿嵌入 | 3-8s | 配合演讲节奏，不宜分散注意力 |

## 13. 首帧 / 末帧规范

### 13.1 首帧（First Frame）——控制视频开头

首帧决定了观众的第一印象。如果 AI 模型支持首帧图（image-to-video），应充分利用；如果不支持，也应在提示词中明确描述开头画面状态。

**首帧应包含的要素**：

| # | 要素 | 说明 | 示例 |
|---|------|------|------|
| 1 | **主体位置** | 主体在画面中的初始位置 | "产品居中放置，正面朝向观众" |
| 2 | **场景状态** | 背景环境的初始状态 | "背景为深灰色渐变，从中心向外变暗" |
| 3 | **光线** | 初始光照条件 | "柔和的顶部光源，在桌面形成均匀照明" |
| 4 | **构图** | 初始画面构图 | "对称构图，主体占画面高度的 40%" |
| 5 | **初始动作状态** | 主体刚开始运动的状态 | "产品处于静止状态，即将开始旋转" |

### 13.2 末帧（Last Frame）——控制视频结尾

末帧决定了观众的最后印象和视频是否适合循环播放。

**末帧应包含的要素**：

| # | 要素 | 说明 | 示例 |
|---|------|------|------|
| 1 | **主体最终状态** | 主体结束时的位置/姿态/状态 | "产品停在正面偏右 15 度的最佳展示角度" |
| 2 | **动作结束状态** | 动作是完成了 / 进行中 / 冻结了 | "旋转动作已完成，产品静止" |
| 3 | **镜头停留位置** | 结尾时镜头的位置 | "镜头停在产品正面微俯视角度" |
| 4 | **情绪 / 氛围** | 结尾传递的感受 | "温暖的高级感，令人想要了解更多" |
| 5 | **循环兼容性** | 末帧是否能自然过渡回首帧 | "末帧画面接近首帧，便于无缝循环播放" |

### 13.3 首末帧写作模板

**首帧描述**：

```text
首帧：[主体] 位于 [位置]，[场景状态]，[光线条件]，[构图]，[即将开始的动作]
```

**末帧描述**：

```text
末帧：[主体] 最终处于 [状态]，[动作完成情况]，[镜头位置]，[氛围]，[是否适合循环]
```

## 14. 风格、光线、色彩、材质规范

本章维度继承自 T-IMG-001（§8-§13），但在视频中有特殊的连续性要求。

### 14.1 风格（Style）

| 图像 vs 视频的差异 | 视频中的额外要求 |
|-------------------|------------------|
| 图像只需一次性风格匹配 | **视频要求全程风格一致** |

**常见问题及对策**：

| 问题 | 表现 | 对策 |
|------|------|------|
| 风格中途跳变 | 前半段写实后半段变成卡通 | 在提示词中加"consistent style throughout" / "maintain the same style for entire video" |
| 风格关键词冲突 | 同时写了"赛博朋克"和"日系清新" | 选定一个主风格，其他作为辅助修饰语 |
| 风格太泛 | 只写了"好看的" | 使用具体风格参考：电影导演风格、艺术流派、知名作品风格 |

### 14.2 光线（Lighting）

| 图像 vs 视频的差异 | 视频中的额外要求 |
|-------------------|------------------|
| 图像是单一光线状态 | **视频中的光线可以也应该有自然变化，但不能闪烁** |

**常见问题及对策**：

| 问题 | 表现 | 对策 |
|------|------|------|
| 光线闪烁 | 画面明暗快速不稳定跳动 | 在负面提示词中加入"flickering light" / "unstable lighting" |
| 光线突然跳变 | 某一帧光线完全改变 | 如果需要光线变化，描述为渐进过程（如"光线缓慢从暖变冷"） |
| 阴影不一致 | 主体移动后阴影不跟随 | 提示"consistent shadow direction" / "shadows follow the subject naturally" |

### 14.3 色彩（Color）

| 图像 vs 视频的差异 | 视频中的额外要求 |
|-------------------|------------------|
| 图像只需整体配色协调 | **视频要求每一帧的色彩都保持统一，不能出现色闪** |

**常见问题及对策**：

| 问题 | 表现 | 对策 |
|------|------|------|
| 色彩偏移 | 视频播放过程中整体色调发生变化 | "consistent color grading throughout" / "stable color palette" |
| 色彩闪烁 | 某些帧出现异常的颜色块 | 负面提示词加入"color flickering" / "color shifting" |
| 色彩溢出 | 主体边缘出现不自然的颜色渗出 | "clean edges" / "no color bleeding" |

### 14.4 材质与细节（Texture & Detail）

| 图像 vs 视频的差异 | 视频中的额外要求 |
|-------------------|------------------|
| 图像关注静态材质表现 | **视频要求材质在运动中保持稳定，不出现纹理跳动或闪烁** |

**常见问题及对策**：

| 问题 | 表现 | 对策 |
|------|------|------|
| 材质闪烁 | 金属/玻璃等材质表面出现不自然的明暗跳动 | "stable material appearance" / "consistent texture, no shimmering" |
| 材质变形 | 运动过程中材质纹理发生扭曲 | "preserve material integrity during motion" / "no texture warping" |
| 细节丢失/增生 | 运动中产品的细节（按钮、接口、刻字）消失或多余出现 | 在提示词中和负面提示词中都明确列出关键细节 |

### 14.5 视频连续性检查清单

在提交视频提示词前，确认以下连续性问题已处理：

| # | 检查项 | 提示词中是否有对应描述 |
|---|--------|---------------------|
| 1 | 风格不跳变 | □ "consistent style" / "maintain style" |
| 2 | 光线不闪烁 | □ 负面词含 "flickering" / 光线变化描述为渐进式 |
| 3 | 色彩不偏移 | □ "stable color" / "consistent grading" |
| 4 | 材质稳定 | □ "stable material" / "no texture shimmering" |
| 5 | 主体不变形 | □ 负面词含 "morphing" / "deformation" |
| 6 | 背景不跳变 | □ 负面词含 "background jumping" / "background shift" |

## 15. 负面提示词规范

### 15.1 视频通用负面提示词

以下负面限制适用于几乎所有视频生成任务：

| # | 负面限制 | 英文（供参考） | 说明 |
|---|---------|---------------|------|
| 1 | 不要水印 | watermark, text overlay | 大部分模型会在角落加水印 |
| 2 | 不要 logo | logo, brand mark | 避免意外出现的品牌标识 |
| 3 | 不要乱码文字 | gibberish text, random letters | AI 视频常生成无法辨认的文字 |
| 4 | 不要闪烁 | flickering, strobe effect | 画面明暗快速跳动 |
| 5 | 不要画面抖动 | camera shake, jittery footage（除非故意手持感） | 无意义的画面震动 |
| 6 | 不要主体变形 | morphing, body distortion | 主体在运动中发生不自然的形变 |
| 7 | 不要多余肢体 | extra limbs, extra fingers | 人物/动物肢体数量异常 |
| 8 | 不要脸部崩坏 | deformed face, bad anatomy, facial distortion | 面部结构异常（人物视频尤其重要） |
| 9 | 不要产品形态变化 | product changing shape, inconsistent product form | 产品外观在视频过程中改变 |
| 10 | 不要背景跳变 | background jumping, scene cutting（除非是有意转场） | 背景突然改变 |
| 11 | 不要过度运动模糊 | excessive motion blur | 因运动导致的严重模糊 |
| 12 | 不要突然切换风格 | sudden style change, style inconsistency | 视频中途画风突变 |
| 13 | 不要不自然转场 | abrupt transition, unnatural cut（除非是有意硬切） | 镜头之间过渡生硬 |
| 14 | 不要低分辨率 | low quality, low resolution, blurry | 画质不清晰 |
| 15 | 不要侵权角色 | copyrighted characters | 避免 IP 侵权问题 |

### 15.2 分类负面词

根据视频类型选择侧重：

**人物/角色视频** 额外添加：

```
bad anatomy, mutated hands, extra fingers, poorly drawn faces,
disfigured, blurry, out of frame, extra limbs, ugly, duplicate,
morbid, mutilated, out of frame, extra fingers, mutated hands,
poorly drawn hands, poorly drawn face, mutation, deformed,
bad proportions, extra limbs, cloned face, disfigured,
gross proportions, malformed limbs, missing arms, missing legs,
extra arms, extra legs, fused fingers, too many fingers,
long neck
```

**产品视频** 额外添加：

```
product deformation, inconsistent shape, changing dimensions,
distorted geometry, warped surface, material inconsistency,
logo appearing, text on product, incorrect reflections
```

**场景/氛围视频** 额外添加：

```
inconsistent lighting, color banding, compression artifacts,
aliasing, noise, grain (unless intentional film grain)
```

### 15.3 ⚠️ 平台兼容性说明

| 平台特性 | 应对策略 |
|---------|---------|
| 支持独立负面提示词字段 | 直接使用上述负面词列表 |
| **不支持**独立负面提示词字段 | 将关键负面限制写入自然语言提示词，格式如："The video should NOT contain: watermark, logo, text, flickering..." |
| 支持负面提示词但有字符限制 | 优先保留最关键的 5-8 条负面限制（水印/logo/变形/闪烁/文字/低质） |

## 16. 平台适配原则

> 本章只提供**通用适配原则**，不涉及具体版本参数。
>
> 各平台的具体参数和最新功能请以官方文档为准。
> 平台专项适配模板将在后续文件中单独创建。

### 16.1 主流视频生成平台概览

| 平台类型 | 代表 | 特点概述 | 提示词语言偏好 |
|---------|------|---------|--------------|
| **Runway** | Gen-3 Alpha / Gen-4 | 运动笔刷控制强，支持首帧/末帧图 | 英文为主 |
| **Pika** | Pika 1.5 / 2.0 | 效果丰富（如爆炸、融化、挤压），上手简单 | 英文 |
| **Kling / 可灵** | Kling 1.5 / 可灵 AI | 中文理解好，时长可达 10s+，支持高分辨率 | 中英文均可 |
| **Luma** | Dream Machine | 运动真实感强，物理模拟较好 | 英文 |
| **Sora** | Sora | 物理世界模拟强，时长较长 | 英文 |
| **豆包 / 即梦** | 字节系 | 中文生态友好，融入字节产品体系 | 中文优先 |
| **其他** | Vidu / Hailuo / Minimax 等 | 各有特色 | 视平台而定 |

### 16.2 通用适配原则

| # | 原则 | 说明 |
|---|------|------|
| 1 | **英文提示词兼容性最广** | 即使是中文友好平台，英文提示词通常也有更好的效果 |
| 2 | **运动强度因平台而异** | 有些平台默认运动幅度大（容易过度），有些偏保守（需要加强动作描述） |
| 3 | **首帧/末帧支持不同** | 不是所有平台都支持图片作为首帧/末帧输入，不支持时改用文字描述 |
| 4 | **负面提示词支持不同** | 见 §15.3 平台兼容性说明 |
| 5 | **最大时长不同** | 提示词中要求的时长不应超过平台上限 |
| 6 | **画面比例支持不同** | 提交前确认平台支持目标比例 |
| 7 | **不要写死参数值** | 如"motion score: 5/10"这类内部参数可能在下个版本改变 |

### 16.3 平台选择建议

根据任务需求选平台（仅供参考，以实际测试为准）：

| 需求特征 | 推荐尝试的平台 | 原因 |
|---------|---------------|------|
| 需要精确控制运动 | Runway（运动笔刷） | 运动控制最精细 |
| 需要有趣/夸张效果 | Pika | 内置特效丰富 |
| 中文需求 / 长视频 | Kling / 可灵 | 中文理解好，支持更长时长 |
| 运动真实感 | Luma / Sora | 物理模拟更自然 |
| 中文优先 / 国内生态 | 豆包 / 即梦 | 中文原生支持 |
| 不确定哪个好 | 同时生成 2-3 个平台版本对比 | 不同平台对不同类型的任务各有优劣 |

## 19. 可复制：视频提示词验收清单

在提交视频提示词之前，逐项检查：

### 基础完整性（6 项）

- [ ] **主体是否清楚**：读者能否仅凭提示词想象出主体长什么样？
- [ ] **场景是否清楚**：环境描述是否足以建立画面空间？
- [ ] **动作是否明确**：有没有说明谁、做什么动作、什么方向、多快？
- [ ] **镜头运动是否明确**：相机怎么动？速度如何？
- [ ] **时间顺序是否明确**：从开始到结束发生了什么？
- [ ] **节奏是否明确**：快还是慢？是否有变速？

### 视觉质量（6 项）

- [ ] **风格是否统一**：全文风格关键词是否一致？有无矛盾？
- [ ] **光线是否连续**：光线描述是否合理？会不会闪烁？
- [ ] **色彩是否统一**：是否有色彩偏移或色闪的风险？
- [ ] **材质是否稳定**：运动中的材质是否会出现闪烁或变形？
- [ ] **首帧是否明确**：视频开头画面是否可预测？
- [ ] **末帧是否明确**：视频结束状态是否可控？

### 负面限制（4 项）

- [ ] **是否有负面提示词**：是否列出了需要排除的因素？
- [ ] **是否避免闪烁**：负面词中是否包含 flickering / 闪烁相关？
- [ ] **是否避免主体变形**：负面词中是否包含 morphing / deformation 相关？
- [ ] **是否避免文字乱码**：负面词中是否包含 text / watermark / logo 相关？

### 技术适配（3 项）

- [ ] **是否说明画面比例**：16:9 / 9:16 / 1:1？
- [ ] **是否适配目标平台**：时长、比例、写法是否符合目标平台？
- [ ] **是否避免水印/logo**：负面词中是否包含？

### 迭代准备（1 项）

- [ ] **是否有下一步修改方向**：如果第一次生成不理想，知道该调哪些维度？

**通过标准**：L1-L2 至少完成基础完整性 6 项 + 负面限制 4 项；L3-L5 建议全部 20 项均 checked。

## 20. 常见错误

| # | 错误 | 表现 | 快速修正 |
|---|------|------|---------|
| 1 | **只写画面，不写动作** | 提示词全是静态画面描述，没有任何动词 | 加入 §9 的动作七要素：谁/什么/方向/速度/幅度/起止/循环 |
| 2 | **只写风格，不写镜头运动** | 写了"电影感""大片风"但没说相机怎么动 | 替换为具体运镜：推/拉/环绕/横移 + 速度 |
| 3 | **没有时间顺序** | 读者不知道视频从头到尾发生了什么 | 加入 §11 的时间结构：开始→变化→结束 |
| 4 | **动作太多** | 一个 5 秒视频写了 8 个动作，每个都做不好 | 砍到 1-2 个核心动作，少即是多 |
| 5 | **镜头运动太复杂** | 又推又拉又环绕又手持，5 秒内换 4 种运镜 | 选一种主运镜贯穿全视频 |
| 6 | **分镜过多** | 8 秒视频切了 10 个镜头，每个不到 1 秒 | 精简到 3-4 个镜头，给每个镜头足够时长 |
| 7 | **主体不一致** | Shot 01 是"银色产品"，Shot 02 变成了"金色产品" | 每个镜头重复完整的外观描述 |
| 8 | **风格跳变** | 前半段写实风，后半段突然变动漫风 | 全文锁定一个主风格 |
| 9 | **光线闪烁** | 视频播放时亮度忽明忽暗 | 负面词加 "flickering" / 提示词加 "stable consistent lighting" |
| 10 | **产品形态变化** | 产品在旋转过程中形状变了 | 负面词加 "product deformation" / "inconsistent form" |
| 11 | **人物脸部崩坏** | 人物视频中面部五官错位或变形 | 负面词加详细的面部负面词（见 §15.2 人物类） |
| 12 | **文字乱码** | 画面中出现无法辨认的文字 | 负面词加 "text, watermark, letters, words, writing" |
| 13 | **平台参数写死** | 提示词里写了 "motion=5, CFG=7" 等具体参数值 | 改为描述性的运动要求，不以具体参数值呈现 |
| 14 | **没有负面提示词** | 完全没有说明"不要什么" | 至少加入基础 8 条负面限制（§15.1 前 8 条） |
| 15 | **没有说明首帧/末帧** | 不知道视频开头和结尾什么样 | 按 §13 补充首帧和末帧描述 |
