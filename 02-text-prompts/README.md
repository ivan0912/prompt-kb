## 内容说明

本目录存放用于文本生成的提示词模板，包括但不限于：
- 写作创作（文章、故事、广告文案）
- 信息处理（总结、翻译、改写）
- 分析研究（数据分析、报告生成）
- 代码开发（代码生成、审查、调试）
- 决策辅助（头脑风暴、规划、评估）

## 已有模板

### T-TEXT-001｜模糊需求转计划类任务 Pipeline

> **文件**: [templates/fuzzy-request-to-plan-pipeline.md](templates/fuzzy-request-to-plan-pipeline.md)
> **版本**: v0.4 | **状态**: ✅ 稳定版 | **来源案例**: [CS-001](../06-case-studies/oral-request-to-learning-plan.md)
>
> **新增能力**：
> - 参考资料机制（AI 优先基于参考资料生成，不确定信息标记为 `[待确认]`）
> - `###` 分隔符规范（角色 / 任务 / 输入 / 输出要求区块化）
> - `[待确认]` 标记格式统一（v0.4 修正，格式一致）
>
> **验证案例**：CS-001（原型） + CS-002（迁移验证 93.3% A），案例逻辑兼容 v0.4，无需重写正文

**解决什么问题**：用户只有模糊目标（如"想做个计划但不知道怎么说"），不知道如何让 AI 生成一个可执行计划。

**核心流程**：

| 步骤 | 名称 | 做什么 | 温度 |
|------|------|--------|------|
| Step 1 | 需求澄清 | 通过提问补全关键信息，输出结构化需求文档 | 0.7 |
| Step 2 | 计划框架 | 设计分阶段骨架表（不含具体内容） | 0.7 |
| Step 3 | 详细计划生成 | 填充完整可执行计划（固定 5 章节结构） | 0.3 |

**推荐使用方式**：单 Agent 顺序 Prompt Chaining（步骤间强串行依赖，无需多 Agent）

**适用场景**（10 类）：

| 场景 | 匹配度 | 说明 |
|------|--------|------|
| 学习计划 | ⭐⭐⭐⭐⭐ | 原型场景，最佳匹配 |
| 健身计划 | ⭐⭐⭐⭐⭐ | 同构：目标→现状→时间→方案 |
| 写作计划 | ⭐⭐⭐⭐ | 调整维度为体裁/篇幅/读者/截止日期 |
| 项目计划 | ⭐⭐⭐⭐ | 增加团队/预算/技术栈/交付物维度 |
| 考试计划 | ⭐⭐⭐⭐⭐ | 时间刚性+目标清晰，天然适合 |
| 内容创作计划 | ⭐⭐⭐⭐ | 增加平台/受众/竞品/变现维度 |
| 职业转型计划 | ⭐⭐⭐⭐ | 高价值场景，建议用进阶版 |
| 产品规划 | ⭐⭐⭐⭐ | 增加用户/市场/竞品/MVP 维度 |
| 运营计划 | ⭐⭐⭐ | 增加当前数据/目标值/资源/渠道维度 |

**不适用场景**：

| 场景 | 为什么不适合 | 替代方案 |
|------|-------------|----------|
| 需要实时数据的任务 | Chaining 不解决数据获取 | ReAct + 工具调用 |
| 法律 / 医疗 / 金融等专业建议 | AI 不能替代持证专业判断 | 必须由专业人士审核 |
| 必须接入外部工具才能完成 | 如写代码并部署、查数据库出报告 | ReAct 或 PAL |
| 用户完全不愿提供任何信息 | 连核心目标都无法确认 | 不在提示词范畴 |

**模板变体**：

| 变体 | 位置 | 适用情况 |
|------|------|----------|
| 标准三步版 | §6→§7→§8 | 默认推荐，需求模糊但用户愿意配合 |
| 最小回答版 | §6 子章节 | 用户怕麻烦，只答 3 个核心问题 |
| 简化 Zero-Shot 版 | §9 | 用户自己心里有数，只需结构化输出框架 |
| 进阶 CoT+GK 版 | §10 | 高价值复杂场景（转行/重要考试），token 成本 3-4 倍 |
