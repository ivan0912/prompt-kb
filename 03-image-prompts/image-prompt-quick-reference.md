## 1. 用途

- 快速把口语化图像需求转成图像提示词；
- 快速检查图像提示词是否完整；
- 快速判断需要补充主体、场景、风格、构图、光线、色彩、细节、负面提示词等；
- 作为 T-IMG-001 完整规范的日常使用入口。

如果需要完整规则、详细示例和完整验收清单，请查看：

[prompt-kb/03-image-prompts/image-prompt-foundation.md](image-prompt-foundation.md)

---

## 2. 图像提示词核心公式

```
图像提示词 = 主体 + 场景 + 风格 + 构图/镜头 + 光线 + 色彩 + 细节/材质 + 氛围 + 画面比例 + 负面提示词 + 平台适配
```

不是每次都要写满所有项。简单任务可以简化，复杂任务才需要完整结构。

## 3. 15 维度速查表

| 维度 | 什么时候必填 | 怎么写 | 常见错误 |
|------|-------------|--------|----------|
| 1. 图像目标 | ⭐⭐⭐ 必须 | 一句话说明用途："一张用于小红书封面的猫咪插画" | ❌ 只写"画一张图"，没说用途 |
| 2. 主体 | ⭐⭐⭐ 必须 | 谁/什么 + 外观 + 状态 + 动作："一只橘色英短猫，圆脸，坐姿" | ❌ "一只猫"——太模糊；❌ 主体太多 |
| 3. 场景 | ⭐⭐ 推荐 | 在哪里 + 环境元素 + 时间："日式房间，榻榻米，午后阳光" | ❌ "室内"——太模糊；❌ 场景和主体不分 |
| 4. 风格 | ⭐⭐⭐ 必须 | 具体风格名，1-2 个："水彩插画风格" | ❌ "好看""高级感"；❌ 风格词堆砌 |
| 5. 构图 | ⭐⭐ 推荐 | 居中/三分法/留白/对称/对角线/俯拍 | ❌ 不写构图——AI 自由发挥；❌ 封面不留白 |
| 6. 镜头/视角 | ⭐⭐ 推荐 | 特写/中景/远景/广角/微距/俯拍/仰拍/环绕感 | ❌ 头像用远景——面部不清 |
| 7. 光线 | ⭐⭐ 推荐 | 自然光/柔光/逆光/霓虹/黄金时刻/电影布光/体积光 | ❌ 不写光线——AI 默认平淡照明 |
| 8. 色彩 | ⭐⭐ 推荐 | 暖色/冷色/高饱和/低饱和/品牌色/莫兰迪 | ❌ "好看的颜色"——不可操作 |
| 9. 材质与细节 | ⭐ 可选 | 服务主体的 3-5 个关键细节："蓬松毛发""金属反光" | ❌ 细节太多过载；❌ 细节不服务主体 |
| 10. 氛围 | ⭐ 可选 | 情绪词："温馨宁静""冷峻""神秘" | ❌ 氛围和风格/色彩矛盾 |
| 11. 画面比例 | ⭐⭐ 推荐 | 16:9/1:1/9:16/4:3/3:4——和用途匹配 | ❌ 小红书封面用 16:9——应为 3:4 或 9:16 |
| 12. 质量要求 | ⭐ 可选 | "高分辨率，4K 级别" | ❌ "8K + 像素风格"——矛盾 |
| 13. 负面提示词 | ⭐⭐ 推荐 | 不要文字/水印/畸形/模糊/真实人物身份还原 | ❌ 不写——可能生成水印、畸形；❌ ChatGPT Images 不支持 |
| 14. 参考图/参考资料 | ⭐ 可选（有参考图时必填用途） | 说明用途：风格参考/构图参考/人物参考/色彩参考 | ❌ 上传参考图不说参考什么 |
| 15. 平台适配说明 | ⭐ 可选（跨平台时推荐） | 目标平台 + 参数建议；版本号以当前平台文档为准 | ❌ 写死版本号；❌ 不区分平台 |

## 4. 标准输入区

```markdown
### 原始需求
[填写你的口语化图像需求]

[封面 / 海报 / 产品图 / 头像 / 社交媒体 / 其他]

### 目标平台
[ChatGPT Images / 豆包 / Midjourney / Stable Diffusion / Flux / Hugging Face / 其他]

[参考图说明 / 风格参考 / 品牌色 / 人物设定 / 场景设定。如果没有，写"无"]

### 输出要求
[中文提示词 / 英文提示词 / 负面提示词 / 多版本变体 / 平台参数建议]
```

## 5. 标准输出区

图像提示词生成器的推荐输出结构：

1. **需求解析**——从口语化需求中提取的关键信息
2. **中文图像提示词**——完整的中文图像提示词
3. **英文图像提示词**——完整的英文图像提示词
4. **负面提示词**——需要排除的元素列表
5. **构图建议**——推荐的构图方式及原因
6. **风格建议**——推荐的艺术风格及原因
7. **平台适配建议**——各平台的参数和格式建议
8. **可选变体**——3 个变体提示词
9. **风险与注意事项**——侵权、身份还原、平台限制
10. **需要补充的问题**——所有 [待确认] 项

**L1-L2 简单任务可以简化**，最少输出：
- 需求解析；
- 中文图像提示词；
- 负面提示词。

## 6. 图像任务复杂度速查

| 等级 | 任务特征 | 推荐做法 | 是否需要完整结构 | 是否需要人工确认 |
|------|----------|----------|------------------|------------------|
| L1 | 简单图片需求（"画只猫"） | 主体 + 风格 + 比例 | ❌ 不需要 | ❌ 不需要 |
| L2 | 有明确主体和风格 | 主体 + 场景 + 风格 + 构图 + 比例 | ❌ 不需要 | ❌ 不需要 |
| L3 | 需要构图/光线/色彩 | 完整 15 维度 | ✅ 推荐 | ⚠️ 可选 |
| L4 | 需要参考图/品牌/多约束 | 完整 15 维度 + 参考图规范 | ✅ 必须 | ✅ 推荐 |
| L5 | 高价值商业图/多版本迭代/需要审核 | 完整 15 维度 + 参考图 + 变体 + 审核 | ✅ 必须 | ✅ 必须 |

## 7. 常用描述词速查

### 主体

人物、产品、动物、建筑、场景、物品、图标、UI 元素、品牌视觉元素

### 场景

室内、室外、城市、自然、办公室、未来空间、古风庭院、科幻基地、咖啡馆、展厅

### 风格

写实、商业摄影、电影感、3D 插画、平面插画、动漫、国风、赛博朋克、极简、水彩、油画、像素风、信息图、产品渲染

### 构图/镜头

中心构图、三分法、对称构图、留白构图、俯拍构图、特写、中景、远景、广角、微距、平视、环绕感

### 光线

自然光、柔光、逆光、霓虹灯、黄金时刻、电影级布光、体积光、高对比、低调光

### 色彩

暖色、冷色、高饱和、低饱和、黑白、蓝紫科技感、莫兰迪色、品牌色、互补色

### 细节/材质

皮肤、布料、金属、玻璃、木材、纸张、水面、发光元素、粒子效果、纹理、道具、背景细节

## 8. 负面提示词速查

常见负面提示词：

- 不要文字
- 不要水印
- 不要 logo
- 不要模糊
- 不要低清
- 不要畸形手指
- 不要多余肢体
- 不要过度曝光
- 不要杂乱背景
- 不要真实人物身份还原
- 不要侵权角色
- 不要敏感元素

> ⚠️ 不同平台对负面提示词支持程度不同。ChatGPT Images 不支持，需改写为正面描述（如"干净的背景"替代"不要杂乱背景"）。Midjourney 用 `--no` 参数。Stable Diffusion / Flux 放 Negative Prompt 区。必要时需改写成自然语言限制。

## 11. 可复制：图像提示词验收清单

每次生成图像提示词后，快速检查：

- [ ] 主体是否清楚？
- [ ] 场景是否清楚？
- [ ] 风格是否具体？
- [ ] 构图是否明确？
- [ ] 镜头/视角是否明确？
- [ ] 光线是否明确？
- [ ] 色彩是否明确？
- [ ] 材质和细节是否服务主体？
- [ ] 是否需要负面提示词？
- [ ] 是否说明画面比例？
- [ ] 是否说明参考图用途？
- [ ] 是否避免真实人物身份还原？
- [ ] 是否避免侵权角色或商标风险？
- [ ] 是否有中文和英文版本？
- [ ] 是否有 [待确认] 标记？
- [ ] 风格词是否不超过 3 个？
- [ ] 是否适配目标平台？
- [ ] 是否有下一步修改方向？

## 12. 常见错误速查

| 错误 | 表现 | 快速修正 |
|------|------|----------|
| 只写风格，不写主体 | "赛博朋克风格，霓虹灯" | 先写主体："穿皮夹克的女孩"，再写风格 |
| 主体太多 | "一只猫、一只狗、一只兔子、一棵树" | 聚焦 1-2 个主体，其他做背景 |
| 场景不清 | "在某个地方" | 至少写室内/室外 + 2-3 个环境元素 |
| 风格词堆砌 | "油画水彩动漫写实3D" | 精简为 1-2 个主风格 |
| 构图缺失 | 不说画面怎么布局 | 至少写"居中"或"特写" |
| 光线缺失 | 不说怎么照亮 | 至少写"自然光"或"柔光" |
| 色彩缺失 | 不说什么色调 | 至少写"暖色"或"冷色" |
| 没有负面提示词 | 不说"不要什么" | 至少写"不要水印、不要文字" |
| 参考图用途不清 | 上传参考图不说参考什么 | 标明"风格参考"/"构图参考"/"色彩参考" |
| 想还原真实人物身份 | "按照这张照片画一个人" | 改为"参考构图和光线，不还原人物身份" |
| 混用多个冲突风格 | "写实 + Q版 + 水彩" | 选一个主风格，其他做辅助修饰 |
| 要求生成文字但没有排版约束 | "画面中有'Hello'" | AI 生成的文字不可控，改用设计工具排版 |

## 13. 推荐使用流程

```
1. 先写原始需求
   ↓
2. 判断使用场景（封面？产品？头像？）
   ↓
3. 确定主体和场景
   ↓
4. 补充风格、构图、光线、色彩
   ↓
5. 补充负面提示词
   ↓
6. 选择目标平台
   ↓
7. 生成 1-3 个变体
   ↓
8. 用验收清单检查（§11）
   ↓
9. 根据生成结果二次优化
```
