## 1. 案例定位

本案例用于验证以下问题：

| # | 验证目标 | 说明 |
|---|----------|------|
| 1 | 口语化需求转结构化提示词 | 能否把用户的自然语言描述转成具备完整视觉维度的图像提示词 |
| 2 | 15 维度覆盖情况 | T-IMG-001 的 15 维度结构是否足够支撑封面图类型的图像生成任务 |
| 3 | quick-reference 可用性 | 日常速查卡是否足够完成此类任务，无需频繁查阅完整规范 |
| 4 | 多平台适配可行性 | 一份通用提示词是否能适配 ChatGPT Images、豆包、Midjourney、Stable Diffusion / Flux |
| 5 | 案例模板沉淀价值 | 是否可以将此案例作为后续封面图类图像提示词任务的可复用起点 |

**不包含**：平台专用参数模板、具体生成结果截图、真实人物描述、商标或品牌相关内容。

---

## 2. 原始需求

> 我想生成一张 Prompt-KB 知识库的封面图，用在 README 或项目介绍里。
> 画面要体现"AI 提示词知识库""结构化思考""多模块协作""可复用模板"的感觉。
> 风格希望是现代、干净、科技感，但不要太夸张。
> 不要出现具体品牌 logo，不要出现真实人物，不要有复杂文字。
> 适合横版封面或 banner。

---

## 3. 使用场景分析

| 分析项 | 本案例判断 | 说明 |
|--------|-----------|------|
| **图片用途** | 项目 README 封面图 / GitHub Banner / 文档顶部图 | 对外展示用途，需要简洁专业 |
| **推荐画面比例** | 16:9 或 3:1（Banner 比例） | 横版封面优先 16:9；窄版 Banner 可用 3:1 |
| **推荐风格** | 现代扁平科技风 / 渐变插画风 | 干净、不夸张、体现结构化和知识系统感 |
| **推荐复杂度等级** | L3（中等复杂，多元素协调） | 多模块、节点、抽象概念图，需要构图和色彩协调 |
| **是否需要参考图** | 否（通用概念图，不需要风格参考图） | 用文字描述风格方向即可 |
| **是否需要人工确认** | 否（色彩方案已固定） | 蓝紫科技感 + 白色/浅灰背景 + 少量青色高光 |
| **是否适合做平台通用提示词** | 是 | 概念性图像，不依赖特定平台能力，通用提示词有效 |

```
一张横版知识库封面图，主体是多个抽象的知识节点，用细线连接成网络结构，
节点旁浮动着几张提示词模板卡片，卡片上有简约几何图标，
背景是深蓝到紫蓝的渐变数字空间，左侧三分之一区域集中主要元素，右侧留白，
节点有轻微发光效果，卡片有淡淡阴影，
整体蓝紫科技感配色，白色和浅灰色节点/卡片，少量青色高光点缀，
现代扁平插画风格，专业、冷静、有序，高分辨率，16:9 横版封面。
```

**特点**：
- 无复杂文字要求
- 无品牌 logo
- 无真实人物
- 不超过 2 个风格词（现代扁平 + 微渐变隐含）

## 7. 负面提示词

**通用负面提示词（适用多数平台）**：

```
no text, no watermark, no logo, no real human faces, no portraits, no brand identity,
no copyright characters, no cluttered background, no low resolution, no blur,
no overly complex details, no strong cyberpunk neon, no dark or horror atmosphere,
no distortion, no ugly artifacts
```

**中文版本**：

```
不要文字，不要水印，不要 logo，不要真实人物，不要人脸，不要品牌标识，
不要侵权角色，不要杂乱背景，不要低清，不要模糊，
不要过度复杂细节，不要强烈赛博朋克霓虹，不要恐怖或阴暗氛围，
不要变形，不要伪影
```

> 注：ChatGPT Images 不支持负面提示词字段，上述内容需直接整合进正向提示词中（例如"不含文字，背景干净"）。

## 8. 3 个变体

### 变体 1：极简科技风

**适合场景**：README 顶部封面图，需要极简大气，文字排版在图像旁

**中文提示词**：
```
极简横版封面，深蓝到紫蓝渐变背景，中央一个发光的几何抽象知识节点，
四周有淡淡的蓝紫色网格线，无装饰元素，
大量留白，现代极简风格，专业冷峻，蓝紫科技感，16:9。
```

**英文提示词**：
```
Minimalist wide-format cover, deep blue to purple-blue gradient background,
a single glowing geometric knowledge node at center, surrounded by faint
blue-purple grid lines, no decorative elements, generous white space,
modern minimalist style, professional and cool, blue-purple tech palette, 16:9.
```

**注意事项**：
- 极简版适合配文字标题使用，图像本身信息量不宜过多
- 不适合单独作为无标题的封面使用

---

### 变体 2：知识库网络风

**适合场景**：文档内页插图，项目介绍页，强调"多模块知识连接"概念

**中文提示词**：
```
横版插画，画面展示多个发光节点通过曲线连接成知识图谱网络，
节点大小不一，代表不同知识模块，背景深蓝到紫蓝渐变，
节点内有简约图标（书本、问号、箭头、灯泡），
中间密集连接区域向两侧延伸，有景深模糊效果，
现代扁平插画风格，蓝紫科技感配色，白色/浅灰节点，16:9。
```

**英文提示词**：
```
Wide-format illustration showing multiple glowing nodes connected by curved lines
forming a knowledge graph network. Nodes vary in size representing different
knowledge modules, deep blue to purple-blue gradient background. Nodes contain
simple icons (book, question mark, arrow, lightbulb). Dense connection zone
at center extends outward with depth-of-field blur. Modern flat illustration
style, blue-purple tech color palette, white/light gray nodes, 16:9.
```

**注意事项**：
- 节点内的图标可能在部分平台无法准确渲染，若图标错误可要求"节点内留空或用抽象几何"
- 景深效果在写实风格模型上效果更好，扁平风格模型可能忽略该要求

---

### 变体 3：模板工作台风

**适合场景**：文档封面，强调"提示词模板""可复用结构""工作台界面"概念

**中文提示词**：
```
横版插画，模拟一个简洁的数字工作台界面，
画面有几张悬浮的提示词模板卡片，卡片上有结构化文本占位符（方块+线条代替真实文字），
卡片之间有连接箭头，背景是浅灰蓝色，干净专业，
整体有轻微立体卡片效果，无文字，无 logo，
现代扁平插画风格，专业整洁，16:9。
```

**英文提示词**：
```
Wide-format illustration simulating a clean digital workbench interface.
Several floating prompt template cards with structured placeholder blocks
(rectangles and lines instead of real text), connected by arrows.
Light gray-blue background, clean and professional. Slight 3D card depth effect.
No text, no logo. Modern flat illustration style, professional and tidy, 16:9.
```

**注意事项**：
- "方块+线条代替真实文字"是减少乱码文字的关键描述，若平台仍生成乱码需强化负面提示词
- 该变体适合用来说明"知识库是结构化工作流工具"，不适合作为纯装饰封面

## 9. 平台适配建议

| 平台 | 建议 |
|------|------|
| **ChatGPT Images** | 直接使用中文提示词即可；不支持负面提示词字段，需将"无文字、背景干净"等描述写入正向提示词；画面比例通过对话指定（"横版16:9"）；如结果不满意可进行多轮对话优化 |
| **豆包** | 中文提示词效果较好；可在提示词末尾加"16:9横版"指定比例；平台界面可设置图片尺寸，建议选择1024×576或对应横版规格；负面提示词可填入独立字段 |
| **Midjourney** | 建议使用英文提示词；比例参数加 `--ar 16:9`；风格参数可加 `--style raw` 降低平台自动美化干扰；负面提示词通过 `--no` 参数传入：`--no text, watermark, logo` |
| **Stable Diffusion / Flux** | 建议使用英文提示词；负面提示词填入 Negative Prompt 字段；可通过 LoRA 或风格模型增强扁平插画风格；建议分辨率 1920×1080（16:9）；Flux 对中文提示词的支持有所改善，可尝试 |
| **Hugging Face 模型** | 根据使用的基础模型选择语言；SDXL 类模型建议英文提示词；部分开源插画风格模型（如 SDXL-Turbo、Animagine 等）对扁平插画风格有良好支持；注意版本间对负面提示词的支持差异 |

> 以上建议基于通用规律，具体平台的参数格式以当前平台官方文档为准，版本号可能发生变化。

## 11. 风险与注意事项

| 风险类型 | 说明 | 应对建议 |
|----------|------|----------|
| **文字生成风险** | 图像生成模型常在卡片、节点等区域自动生成乱码或英文 | 强化负面提示词"no text"，并在正向提示词中说明"卡片上用方块和线条代替文字" |
| **logo / 商标风险** | 模型可能将"科技感"联想成常见科技公司 logo | 明确要求"无品牌标识""无 logo"，避免描述特定公司产品 |
| **真实人物风险** | 本案例无人物需求，风险低 | 负面提示词中已包含"无真实人物""无人脸"，足够覆盖 |
| **风格过度堆砌风险** | 同时写"现代""科技感""干净""未来感"可能导致风格混乱 | 只保留 1-2 个核心风格词，其余用氛围词（"专业、冷静"）辅助 |
| **画面过于复杂风险** | 节点网络 + 模板卡片 + 图标可能导致画面拥挤 | 强调"右侧留白"和"三分法构图"，或使用变体 1（极简版）降低复杂度 |
| **平台理解差异** | "扁平插画"在不同模型中效果差异大；ChatGPT Images 倾向生成更写实的图像 | 各平台按 §9 建议调整，必要时增加风格参考图或调整提示词措辞 |
